How we calculate these metrics

Balance = free + locked. Asset value = balance x direct asset/USDT ticker price. Weight = asset value / total priced value x 100. Alert comparisons use unrounded weights; displayed percentages are rounded. USDT is the quote unit, not a guarantee of USD parity.

Only assets with a direct USDT price are valued. Missing prices make totals and alerts partial. The concentration index is the sum of squared allocation fractions: nearer 1 means more concentrated. It is not a volatility measure, loss forecast, or investment recommendation.
